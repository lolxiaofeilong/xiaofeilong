# 小小数数家

一个帮助小朋友练习数数的中文网页小游戏。孩子可以根据题目点击图案，检查自己是否数对，并通过星星获得鼓励。

## 功能

- 5 道数数练习题，数字范围为 2 到 7。
- 点击图案进行计数，再点击“检查答案”得到反馈。
- 支持“重新数”和“下一题”。
- 使用大按钮、大字号和明亮配色，适合低龄儿童操作。
- 纯 HTML、CSS、JavaScript 实现，无需安装依赖。

## 运行方式

直接打开 `index.html`，或启动一个本地静态服务器：

```bash
python3 -m http.server 4173
```

然后访问：

```text
http://localhost:4173
```
